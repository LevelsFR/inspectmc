# Security Policy

## Supported version

Security fixes are evaluated for the current public InspectMC release line.

## Reporting a vulnerability

Please do not publish a security vulnerability as a public GitHub issue.

Use a private channel instead:

- GitHub private vulnerability reporting, when available for this repository.
- Our Story Network Discord: https://discord.gg/kb8NSTF45n and contact LevelsFR privately.

Include the affected InspectMC version, Minecraft version, loader, reproduction steps and any relevant logs.

## Scope

Security reports should concern InspectMC itself or its documented integrations. General Minecraft, loader, Java, server-hosting or unrelated mod vulnerabilities should be reported to their respective maintainers.
